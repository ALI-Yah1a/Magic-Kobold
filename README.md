# MAGIC-KOBOLD V.1.0
- MAGIC-KOBOLD is a 2D platformer game with 5 levels. Complete all the objectives to win each level!
- The primary challenge is to attack the enemies by the sword to kill them and collect all the coins.
- The main menu is extremely illustrative, as it catches the vibes of the game 
# IMPORTANT NOTE
- This is the first version of the game, it has some incomplete sections (e.g., levels), however there is still only 2 levels left.
## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.
## How To Play The Game?
- To play the game correctly, you should click the "New Game" button in the main menu after running the game. Then select the one of the 5 levels.
- As I said before, the only way to complete the level is by defeating all the enemies by the sword of the warrior, and collecting all the coins, and get the trophy at the end of the level in order to unlock the next level.
- All the attacks have same damage effect on the enemies.
- If get too close to the enemies, they will prepare to attack you and their speed will increase untill they strike.
- You must prevent them from successfully attacking you, or you will lose.
- Each of enemies in every level needs two successful attacks to kill them.



## Levels Progress
- After completing the first level and get the trophy the next level will be unlocked and the level progress will be updating to the current new level and the progress is restored unless quiting the game.

  
## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level and you can hold shift to run.
- The player can jump using the spacebar or W button.
- You can attack using the LMB or the E button for the attack.
- Using Shift for the dash.
- Using ESC for pause.
